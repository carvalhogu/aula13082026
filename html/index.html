Teste de Repositorio

1. O que é um Repositório? Definição: É basicamente a pasta do seu projeto gerenciada pelo Git. Ele contém o diretório de trabalho (onde você edita os arquivos) e o banco de dados interno do Git. Pasta Oculta (.git): Quando você inicializa um repositório (git init), o Git cria uma pasta oculta chamada .git. É nela que fica todo o histórico de versões, configurações e registros de commits. Deletar essa pasta apaga todo o histórico do Git (mas mantém seus arquivos atuais).
